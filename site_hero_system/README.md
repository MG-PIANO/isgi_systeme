## Comment Déployer sur Vercel (2 Méthodes Simples)

### Méthode 1 : En ligne de commande avec `npx vercel` (Recommandé - 30 secondes)

Ouvrez un terminal dans ce dossier et tapez :

```bash
npx vercel
```

1. Répondez `y` pour confirmer le déploiement.
2. Choisissez votre compte Vercel.
3. Appuyez sur **Entrée** à chaque question pour valider les paramètres par défaut.
4. Pour déployer en production finale avec votre domaine public Vercel :
   ```bash
   npx vercel --prod
   ```

Votre site sera immédiatement en ligne (ex: `https://hero-system.vercel.app`) !

---

### Méthode 2 : Depuis le Dashboard Vercel (vercel.com)

1. Rendez-vous sur [vercel.com](https://vercel.com) et connectez-vous avec votre compte GitHub.
2. Cliquez sur **« Add New... »** > **« Project »**.
3. Sélectionnez le dépôt `isgi_systeme`.
4. Dans **« Root Directory »**, cliquez sur **Edit** et sélectionnez le dossier :
   ```
   site_hero_system
   ```
5. Cliquez sur **« Deploy »**.
6. En 10 secondes, votre site est en ligne avec certificat SSL HTTPS gratuit et CDN mondial !
